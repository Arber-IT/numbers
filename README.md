# Number Frequency Analyzer

An intuitive, web-based tool designed to process, count, and analyze multiple sets of lottery numbers (such as Wednesday and Saturday draws) to generate real-time frequency statistics.

## 🚀 Features

* **Multi-Set Input:** Allows users to input multiple rows or series of lottery numbers simultaneously.
* **Frequency Counting:** Automatically calculates how many times each number appears across all datasets.
* **Smart Sorting:** Generates a dynamically sorted list/table where the most frequently drawn numbers appear at the very top.
* **Tabular Overview:** Displays statistics in a clean, highly structured tabular format for quick data analysis.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for the data input and statistical tables.
* **JavaScript:** Core logic for parsing text inputs, executing the counting algorithms, and handling the dynamic sorting.
* **CSS3:** Clean and responsive user interface layout.

## 📈 Future Enhancements

* Add data visualization charts (bar charts/graphs) for better visual feedback.
* Allow importing CSV files directly from official lottery websites.
* Save past analysis history using browser local storage.
